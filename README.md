# Random Quote Machine

A responsive random quote generator built with React and JavaScript.

## Overview

Random Quote Machine is a web application that displays random quotes along with their authors. Users can generate new quotes, enjoy randomly changing background colors, and share quotes on social media.

Quotes are retrieved from the [DummyJSON Quotes API](https://dummyjson.com/quotes/random).

## Features

- Fetch and display random quotes from an external API.
- Display the quote's author.
- Generate a new quote with a button click.
- Change the background color randomly when a new quote is generated.
- Smooth fade transition when quotes change.
- Share quotes on Twitter and Tumblr.
- Responsive layout for different screen sizes.

## Technologies

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Font Awesome
- DummyJSON Quotes API

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd random-quote-machine
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## API

This project uses the [DummyJSON Random Quotes API](https://dummyjson.com/quotes/random) to retrieve random quotes and authors.
